# Discovery intake (Replit-safe)

## What changed

1. **Mixed themes** — broad categories are **sampled without replacement** (not first-N Europe-fixed order); registry rounds are shuffled and interleaved.
2. **Approachable preference** — web discovery ranks candidates using public signals (founder/operator, recent activity, practical surface) before tight admission budgets.
3. **Case Bureau** — discovery premise prefers active operators over famous-but-unreachable trophy names.

## Apply after import

```bash
node scripts/apply-discovery-intake.mjs
```

Also runs from `scripts/post-merge.sh`.

## Rules

- Real public data only — score never invents openness or contacts
- Variety of ponds, preference for people worth a proposal
- Optional FAA remains optional (`skipFaa` default true)
