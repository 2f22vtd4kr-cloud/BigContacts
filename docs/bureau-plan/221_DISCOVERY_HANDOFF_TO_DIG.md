# Volume 221 — Discovery → Dig Handoff

## Contract

Every admitted entity should carry metadata the dig can use:

- `discoveryBasis` / notes snippet
- `companyName` when known
- `sourceUrls` or sourceRegistries
- `lane` optional

## Dig start

Target contact agent objective: research **this person**, with company context if present — free dig, not “re-run discovery templates.”

## Feedback loop (future)

If dig repeatedly returns empty on a lane, discovery agent should downweight that lane — **learned preference**, not a hardcoded ban list only.

## Anti-pattern

Discovery inserts 500 names; dig never runs; operator sees empty cards and blames dig only. **Discovery volume must match dig capacity** (targetCount, researchLimit).
