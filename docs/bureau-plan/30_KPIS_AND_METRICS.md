# Volume 30 — KPIs and Metrics

**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

## Product KPIs

| KPI | Definition | Target direction |
|-----|------------|------------------|
| Personal precision | direct_* claims that survive independent audit | Up |
| Org honesty rate | org routes correctly labeled | Up |
| Promote success | dig with URL facts → non-empty card when allowed | Up |
| Empty-after-dig rate | visits with facts but empty card | Down |
| Collision false-promote | wrong-family personal claims | Down |
| Integrity-ok run rate | batches started with integrity ok | Up |
| Status availability | healthz/status success under dig | Up |
| Free-dig evidence | trajectories with model-invented queries | Up |

## Anti-KPIs (do not optimize)

- Commit count
- Number of tools mentioned in marketing
- Length of dig log without card improvement
- Word count of plans without scoreboard wins
