# Volume 169 — Empty Card Is a Bug (Until Proven Otherwise)

## Default diagnosis

If the target is public-web-findable and the card is empty after a research job:

1. Assume **bug** (L-NO-DIG, L-PROMOTE, L-OVERWRITE, L-UI-HIDE, L-SCRIPT)
2. Prove otherwise with DigSpan + evidence + healthz

Do **not** default to “they must be private.”

## Proof of legitimate empty

Only acceptable when:

- Dig shows real search/visit work, and
- Evidence bag is empty of non-trash vectors, and
- Baseline chat also finds nothing on the same date, and
- Integrity was ok

That triple match is rare for issuer-linked names. Treat it as exceptional.

## Operator workflow on empty

1. Open DigSpan — any web_search/visit?
2. Open evidence count
3. Rehydrate
4. Compare to a 2-minute manual Google of `Name Company IR` / `Name SEC`
5. File L-code in COMPARE
