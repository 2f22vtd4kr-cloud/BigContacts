# Volume 244 — Token Budget Honesty

## External fact

Multi-agent research can cost ~15× single chat; token use drives much of measured research quality variance. Parallelism is not free.

## Apex policy

- Default contact path: **one dig executor** (predictable cost)
- Discovery parallelism only for **independent lanes**
- Depth tiers scale dig iterations/timeout, not number of conflicting writers
- Scoreboard runs must record depth + whether discovery ran

## Anti-pattern

Spawning more agents because the card is empty — fix observation/promote/ownership first.
