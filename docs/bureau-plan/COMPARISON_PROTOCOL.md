# Apex Atlas — Same-Target Comparison Protocol

For each Bureau batch, freeze the admitted targets before independent research begins. The independent researcher must receive the same target identities but no Bureau trajectory or conclusions.

Record for every target:
- identity correctness
- strongest primary/public source
- direct contact route, if any
- credible intermediary route, if any
- organization-only routes that must not be mislabeled personal
- evidence URLs
- unsupported or weak claims
- missed useful sources
- search/tool decisions
- approximate research effort
- stopping rationale

The comparison must answer whether Apex is actually better than a capable general-purpose LLM researcher, not merely whether Apex found more rows. A larger row count with weaker identity or provenance is a regression.

The comparison is observational. It must never be fed backward as a hidden target-ranking or query-selection rule.
