# Volume 302 — Fixture Pack v1

## Purpose

Stable entity classes for scoreboard and COMPARE—not a dig script.

## Classes

1. **Issuer-trap** — public company filer; issuer phone easy, notice line better  
2. **Org-only** — strong IR/main line, weak personal  
3. **Collision** — common name / same first name risk  
4. **Evidence-rich empty card** — dig ran; promote failed historically  
5. **Deceased/stale** — must not look like live outreach target  
6. **Clean dig win** — known public firm HQ or notice line  

## Usage
