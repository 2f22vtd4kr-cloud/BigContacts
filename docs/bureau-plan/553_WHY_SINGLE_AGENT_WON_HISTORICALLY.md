# Volume 553 — Why a Single Agent Won Historically

## Mechanisms
1. Free query invention vs force-hop budget burn
2. Reading primary pages vs promoting issuer CIK phones
3. Stopping when enough vs refuse-done funnels
4. Responsive chat vs status plane death under dig
5. Honest uncertainty vs org-as-direct labeling

## Implication
Apex wins by removing (1–3) and (5) in product code and by keeping (4) operable—not by adding more phases.
