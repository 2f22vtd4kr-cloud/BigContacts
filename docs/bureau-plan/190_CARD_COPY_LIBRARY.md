# Volume 190 — Card Copy Library (Validate Before Outreach)

## Standard suffixes

- Personal phone: `Validate before outreach.`
- Notice: `SEC notice-line / authorized contact. Validate before outreach.`
- Org main: `Organization route (company/registrant/IR). Validate before outreach.`
- Email org role: `Role inbox — organization route.`
- LinkedIn: `Public profile — confirm identity before message.`

## Forbidden copy

- “Verified personal” without human verification action
- “Guaranteed direct dial”
- Shaming org routes (“low quality only”)

## contactMethod field

Single string, human-readable, may combine best route explanation. Not a substitute for structured fields.
