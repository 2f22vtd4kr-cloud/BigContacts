# Volume 105 — When Determinism Is OK

**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

Deterministic code is correct for:

1. HTML CONTACT FACTS extract (tool output enrichment)  
2. Sanitizers  
3. Identity collision  
4. Outcome mapping  
5. EDGAR/CH parsers  
6. Job lock / pause / stop  
7. **One** thin recovery search+visit if **all** dig LLMs fail  

Deterministic code is **incorrect** as a substitute for dig turns when LLMs are healthy.
