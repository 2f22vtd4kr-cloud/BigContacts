# Volume 56 — Trajectory Quality Bar

**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

A healthy dig trajectory for a public company principal should usually show:

1. At least one model-invented web_search query containing the person or company
2. At least one visit to a non-aggregator primary host when SERP returns one
3. DigSpan entries matching those tools
4. No force_* controller lines on current tip

Absence of (1)–(2) with integrity ok → investigate dig freedom regression.
