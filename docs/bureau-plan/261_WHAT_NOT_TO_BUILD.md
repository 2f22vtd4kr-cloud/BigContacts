1. **force_*** dig hop controllers — free dig is the product.
2. **Second brain** racing dig on the same card (parallel scripted OSINT as primary).
3. **Fake scoreboard pass** while `bureauIntegrity=critical`.
4. **Auto-win COMPARE** from chat API without human review (vol 250).
5. **Discovery-first** on single-target Dig contacts.
6. **MCTS as primary dig** on profile (MCTS is optional path research only).

- Better search/LLM secrets and provider failover
- Trajectory debugging when dig returns empty (vol 247)
