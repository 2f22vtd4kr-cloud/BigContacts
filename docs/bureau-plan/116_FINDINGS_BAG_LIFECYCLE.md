**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

## Lifecycle

1. Empty at dig start  
2. Model may return findings on done  
3. CONTACT FACTS from HTML merge into bag during visits  
4. Footprint/registry tool results may merge when structured  
5. Bag shown as FINDINGS SO FAR each llmStep  
6. On terminal dig: bag → evidence persist → promote attempt  

## Rules

- Bag never invents values not from tools/HTML  
- done with empty findings array is OK if bag already holds contacts  
- Promote reads bag and durable evidence, not trajectory prose alone
