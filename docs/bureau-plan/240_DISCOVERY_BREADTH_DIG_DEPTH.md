# Volume 240 — Discovery = Breadth, Dig = Depth

## Industry split

| Layer | Nature | Apex |
|-------|--------|------|
| Breadth-first research | Many independent threads | Discovery agent / optional parallel lanes |
| Depth-first on one subject | Sequential tool loop on one identity | Target contact dig |
| Synthesis | Merge + attribute | Intake rank + promote + present |

## Operator mental model

1. **Discover** who is worth a desk slot (public basis)
2. **Dig** that person for routes
3. **Show** all attributable routes on the card

Mixing “discover contacts while discovering people” in one template blast confuses both.

## Effort scaling

- Empty desk, discoveryFirst: invest discovery tokens
- Known VIP singleTargetId: skip discovery, full dig budget
- researchLimit caps how many digs follow discovery so breadth cannot starve depth
