# Volume 227 — Control Flow by Mode

## Mode 1 — Single-target re-cook (outreach proof)

```
Operator → Atlas (singleTargetId)
  → Orchestrator sets depth
  → Target Contact Agent (dig) → Tools pool
  → Persist + promote + present
  → Card
```

Boss/RH **optional/absent**. Discovery **skipped**.

## Mode 2 — Discovery-first desk fill

```
Operator → Atlas (discoveryFirst)
  → Discovery agent (preferred) or template fallback
  → Intake admit people
  → For each researchLimit: dig → promote → card
```

## Mode 3 — Case Bureau adaptive (when enabled)

```
Case file → Right-hand advice → Boss decision
  → Investigator brief → tools (subset)
  → Case update → loop until stop
```

Must not override Mode 1 card ownership when both run on same entity.

## Mode 4 — Degraded integrity

```
No search providers / no agentic LLM
  → healthz critical
  → Do not claim quality COMPARE
  → Optional deterministic recovery only after dig LLM total fail
```
