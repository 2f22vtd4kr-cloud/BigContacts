# Volume 554 — Multi-Tool Advantage When Real

## When tools help
Parallel SERP providers, browser escalate, EDGAR notice parse, Companies House officers, footprint CLIs—**when the model chooses them** and results promote.

## When tools do not help
Tools fired by scripts without model judgment; tools whose outputs never reach the card; tools that overwrite better dig data.

## Design test
If removing the model still produces the same tool sequence, the sequence is a script—not a bureau.
