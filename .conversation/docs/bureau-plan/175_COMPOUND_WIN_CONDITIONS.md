# Volume 175 — Compound Win Conditions vs Single LLM

## Chat agent strengths

- Flexible multi-hop reasoning in one session
- No buggy promote layer
- User sees whatever the model typed

## Apex must match those and add

| Apex layer | Win condition |
|------------|----------------|
| Free dig | At least as many useful search/visit hops |
| Evidence | Survives session; rehydrate later |
| Multi-provider | Recall when one SERP fails |
| Registries | Structured hits chat may skip |
| Card | One-click dial/mail; durable |
| Graph | Related paths |
| Trajectory | Debuggable |

## Failure mode this volume names

**“Pipeline theater”**: many phases, empty REACH. Operator should treat pipeline theater as severity equal to dig-down.
