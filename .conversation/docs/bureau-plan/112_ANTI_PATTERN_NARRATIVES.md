# Volume 112 — Anti-Pattern Narratives

**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

## AP1 — Scripted dig to chase scoreboard

Symptom: engineer adds force hops after a loss.  
Effect: trajectories look busy; model skill unused; single agent still wins next week.  
Replace with: promote/identity tickets only.

## AP2 — Prompt that is a playbook

Symptom: dig system prompt 200 lines of “always do X then Y.”  
Effect: same as force hops.  
Replace with: goals + tools + findings.

## AP3 — Fake LIVE

Symptom: Perplexity or dig shows LIVE with 0 keys or idle job.  
Effect: operator distrust.  
Replace with: offline/idle honesty.

## AP4 — Commit theater

Symptom: hundreds of commits, same empty card.  
Effect: no superiority.  
Replace with: Vol 68 scoreboard.

## AP5 — Boss as dig failover narrator only

Symptom: Boss never sets goals; only RH speaks.  
Effect: no planner role.  
Replace with: Boss objective at start; RH narrates events.
