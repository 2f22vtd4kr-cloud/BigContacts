# Volume 162 — Notes and Card Summary Field

## Role of notes / llmCardSummary

Context for outreach first line — role, issuer, filing hook — **not** a dumping ground that replaces structured contacts.

## Rules

- Structured phone/email/linkedin always win over notes text for REACH.
- Summaries must not invent contacts; final review already constrained.
- Strip timeout boilerplate on re-write.
- UI: collapsible; default collapsed on mobile.

## Anti-pattern

Putting the only phone solely in notes while columns empty — promote must lift structured values.
