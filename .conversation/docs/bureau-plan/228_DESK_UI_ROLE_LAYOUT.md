# Volume 228 — Desk UI Role Layout

## Zones mapped to architecture

| UI zone | Shows |
|---------|--------|
| Integrity strip | Tools pool health (search slots, LLM slots) |
| Launch | Orchestrator inputs |
| DigSpan / trajectory | Investigator + dig + tool spans (`agentName`) |
| Bureau live log | boss / right_hand / web / tool / discovery actors |
| Card / ContactSurface | Promote+present output only |
| Scheme nodes | Tools **used**, not full pool catalog |

## Actor colors (suggestion)

- boss: indigo
- right_hand: teal
- investigator/dig: blue
- tool: slate
- discovery: amber
- system: gray

## Operator education one-liner

**Boss plans case work. Dig recovers contacts. Tools only run when dig (or discovery) asks.**
