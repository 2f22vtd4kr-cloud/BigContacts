# Volume 152 — Plan Word Budget and Discipline

## Goal

~**400,000 words** of bureau plan material is a **capacity target** for exhaustive operative specification across OSINT methods, UI, evaluation, failure modes, and batch roadmaps — not a requirement to pad.

## Current baseline

Volumes 1–136 era + implementation status landed near **~28k words**. Remaining budget is large; use it for:

- Method depth (EDGAR field-level, registry quirks, visit extraction),
- UI pixel-level contracts,
- Evaluation datasets,
- Provider incident runbooks,
- Multilingual HNWI sources,
- Legal/ethics boundaries,

not repeated slogans.

## Writing rules

1. Every volume states **problem → rule → acceptance**.
2. Cite external shifts with date and Apex mapping.
3. Prefer tables and checklists for operator use.
4. Link to code paths by module name when known.
5. After each ~5k–15k words of new plan, ship a **batch** or an operator proof artifact.

## Anti-padding

Reject volumes that only restate “free dig good / scripts bad” without new acceptance or method content. Doctrine is fixed in 137–141; later volumes **specialize**.
