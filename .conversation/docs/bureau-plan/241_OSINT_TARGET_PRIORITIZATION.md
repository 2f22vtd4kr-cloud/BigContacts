# Volume 241 — OSINT Target Prioritization (Public, Outreach-Oriented)

## External signals (allocator / HNW list practice, adapted to public-only Apex)

Prioritize targets with:

1. **Regulatory or filing footprint** (ADV, SC13, Forms 3/4, CH officers)
2. **Named role + organization** (not listicle-only)
3. **Liquidity / trigger context when public** (IPO, M&A press) — optional lane
4. **Relationship anchors** (board, foundation trustee) that create dig hooks
5. **Approachability** — public IR/company surface exists

Deprioritize:

- Fame-only trophies with no business filing surface
- Shells without named humans
- Ambiguous names without issuer binding

## Analyst discipline (evidence-based profiles)

OSINT profiling guidance stresses: neutral language, primary sources, source evaluation, **information gaps** explicit. Apex card copy already says validate before outreach; discovery basis must state gaps honestly (“role clear, phone unknown”).

## Apex does not

Build adversarial “targeting packages” against private families. Purpose is **professional outreach using public routes**, with honest labeling.
