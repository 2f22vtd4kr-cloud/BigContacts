# Volume 68 — Operator Scoreboard SOP (Do This, Not Debates)

**Part of:** APEX_ATLAS_MASTER_BUREAU_PLAN

## Every comparison session

1. Record tip `git log -1 --oneline`  
2. `GET /api/healthz` → integrity ok  
3. `RESEARCH_DEPTH=standard` or deep  
4. Re-cook or batch fixture names (Vol 63 classes)  
5. For each name write: outcome, phone, email, phoneSource, notes  
6. Independent primary-source pass (SEC/company site only for “win” claims)  
7. Fill template Vol 35  
8. Open tickets only in A/B/C categories  

## Time box

90–120 minutes for 8 names. Longer means process failure, not more chat.

## Pass criterion for a tip

≥60% of fixtures Apex wins or ties on honesty+primary line; zero wrong-person directs; empty-after-dig = 0 on digs that extracted URL facts.
