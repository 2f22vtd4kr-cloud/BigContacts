# Volume 170 — Depth Means More Surface, Not More Scripts

## Semantics

| Depth | Meaning |
|-------|---------|
| fast | Shorter budget; still free dig; still promote all findings |
| standard | Default single-target; more iterations/timeout to **cover surface map** |
| deep | VIP; maximize visits to IR/filings/team pages |

Depth increases **opportunity** for the model to hit the surface map. It does not add force_* steps.

## Anti-pattern

Using “fast” on single-target scoreboard runs, then blaming the target for emptiness.

## Policy

- singleTargetId → standard minimum (already in code direction)
- Scoreboard fixtures → standard or deep
- Bulk discovery queue → fast acceptable
