# Volume 291 — Discovery Agent Quality Metrics

## North star

Discovery succeeds when admitted people have **basis URLs** and later digs can put routes on the card—not when template query counts are high.

## Metrics

| Metric | Good direction |
|--------|----------------|
| Admits with ≥1 sourceUrl | Up |
| Fame/shell reject rate | Appropriate, not total |
| Duplicate admit rate | Down |
| Post-dig non-empty card rate on admits | Up |
| Template fallback frequency | Down over time |

## Anti-metrics

- “Queries fired”
- “Categories covered” from the old template farm
- Parallel discovery writers on the same phone fields
