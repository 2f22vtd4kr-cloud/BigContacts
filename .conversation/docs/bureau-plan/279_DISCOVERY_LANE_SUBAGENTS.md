# Volume 279 — Discovery Lane Subagents (Conditional)

## When this is allowed

Only if **admit quality plateaus** after free discovery agent is live: too few basis-URL candidates, or systematic miss of a public lane (e.g. recent SC13 individuals) while dig quality on admitted people is already good.

## Pattern (Anthropic-aligned)

- **Lead** states independent facets (lane A: recent 13D individuals; lane B: IR-linked officers).
- **Subagents** each get a brief: objective, output schema (name, role, company, sourceUrls), tools allowed, **no spawn-subagent tool**.
- **Lead synthesizes** and dedupes before intake—not three writers inserting the same person.

## Hard constraints

| Constraint | Rule |
|------------|------|
| Parallelism | Facets must not write the same contact columns |
| Contact ownership | Discovery still **does not promote** phones/emails to dig-owned fields |
| Effort scaling | Trivial sessions → one discovery agent; not 50 lane bots |
| Dig | Unchanged single executor per target |

## Non-goal

Parallel “phone agent / email agent / LinkedIn agent” on one HNWI. That reintroduces dual-brain card writes.
