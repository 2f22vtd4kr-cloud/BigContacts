# Apex Atlas buttons

Palette: `#00B3B8` teal · `#9CFF1A` lime · `#111827` navy · `#F8FAFC` white · `#FF4D6D` coral

Inspired by Figma animated-gradient CTA patterns; **only primary actions animate**.

| Role | Class | Motion | Use |
|------|--------|--------|-----|
| **Primary** | `.atlas-launch-cta` | Slow teal↔lime gradient shift | Launch Apex Atlas only |
| **Secondary** | `.atlas-btn-secondary` / `.atlas-outline-btn` | None | Secondary actions |
| **Success** | `.atlas-btn-success` | None | Resume / live accents |
| **Danger** | `.atlas-btn-danger` | None | Stop |
| **Pause** | amber outline | None | Pause run |

Do **not** put animated gradients on every control — hierarchy must stay obvious.
