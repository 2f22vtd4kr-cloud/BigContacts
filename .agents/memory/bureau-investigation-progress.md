name: Bureau investigation progress
description: Sentient contact-vector coverage for Case Bureau without rigid pipelines.

Apex Atlas Case Bureau tracks standard contact vectors (email, phone, LinkedIn, Instagram, Twitter/X, Telegram, TikTok, website, registries, username footprint) on every target-scoped case via `investigationProgress`.

**Why:** The Boss and right-hand must not forget to ring Instagram, Telegram, phones, Sherlock/Maigret, and registries while chasing one hypothesis. Coverage is gap-driven priority, not a fixed ordered pipeline.

**How to apply:**
- All discovered contact routes remain visible in the UI.
- Verified personal routes are marked (`marker: verified_personal`); organization and review routes stay available.
- Boss investigator prompts must be human-like and adaptive, name pending vectors when relevant, and require exact public values only.
- Never invent contacts. Real public data only.
- Replit-safe: pure TypeScript, no new infrastructure.
