---
name: Entity taxonomy UI
description: Shared presentation rules for the four entity classes across web and mobile surfaces
---

The interface treats HNWI, Corporation, Trust, and Gatekeeper as distinct operating contexts rather than rendering every record as a person. Each class has its own label, color, evidence vocabulary, metric, and next action; wealth is only the primary metric for HNWI records.

**Why:** The product stores companies, trusts, and access nodes alongside people, so person-centric labels and wealth-only fields mislead research decisions.

**How to apply:** Reuse the shared taxonomy for ledger filters, cards, profile heroes, empty states, and mobile targets. Keep “entity” as the neutral umbrella and only use outreach language when the record has a real access vector.
