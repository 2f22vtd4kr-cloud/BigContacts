---
name: Executive contact handoff
description: Durable rule for finding executive routes behind property/SPV corporations
---

For special-purpose corporations and property vehicles, exact-name searching is insufficient. The contact workflow must resolve the parent fund or operating group, fetch its official team/contact pages, preserve name aliases, and attach each executive email/phone to the named person as review-only evidence with the exact source URL. A company-domain executive route may remain a candidate rather than a verified personal contact, but it must not disappear.

**Why:** An Amaron property-vehicle run found registry officers but missed named executives and direct routes that were plainly present on the parent group's official contact page. The failure was discovery/attribution, not a justified contact-validation rejection.

**How to apply:** When the target is an SPV, holding company, or zero-employee property entity, run a parent-group expansion lane before broad forensic tooling. Query shortened/alias names (for example, a registry full name and the executive's common name), and store person-scoped contact evidence separately from the corporation's primary contact fields.
