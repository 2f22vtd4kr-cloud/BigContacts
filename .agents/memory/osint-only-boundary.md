name: OSINT-only product boundary
description: Apex Atlas is research/evidence-only; legacy CRM, outreach, pitch, and communication fields are compatibility data and must not power behavior.

Apex Atlas must remain strictly an OSINT and public-evidence research tool. Do not reintroduce pitch generation, outreach copy, CRM mutation, lead creation, communication approval, message export, or communication artifacts. Research sessions may expose evidence paths, attribution, access assessment, scorecards, and audit history, but not instructions or state for contacting a person.

**Why:** The product requirement is explicit, and contact/access safeguards depend on keeping wealth, identity, evidence, and reachability separate from communication workflows.

**How to apply:** Treat historical schema columns and generated client names as compatibility-only. New routes, UI actions, telemetry tool IDs, persona findings, and docs must use research/evidence terminology and fail closed for any communication behavior.
